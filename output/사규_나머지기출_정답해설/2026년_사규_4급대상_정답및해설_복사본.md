작성일: 2026-10-12 | 원본을 보존한 별도 학습용 복사본

객관식·OX 20문항(4점×20=80점), 주관식 5문항(20점), 총 100점. 회사 공식 정답과 부분점수 기준은 제공되지 않았다.

## 3. 객관식·OX 해설

### 1번. 회사 신분·직무를 이용한 수익 콘텐츠

**답·판정: O 예상 / 겸직 상세 기준 필요**

> 회사에 소속된 임직원의 신분을 이용하거나 직무를 활용하여 콘텐츠 작성 및 경제적 이익을 얻는 것도 겸직에 해당한다. ( ① ○   ② X ) (     )

회사 임직원 신분·직무를 이용해 수익 콘텐츠를 만드는 활동은 출제 의도상 겸직에 해당한다. 현재 사규19쪽은 무승인 타 직업·협조와 직위를 이용한 이익 취득을 금지한다. 다만 콘텐츠 활동을 어떤 조건에서 겸직으로 분류하는지 직접 적은 세칙은 없으므로 회사가 모든 개인 콘텐츠 활동을 금지한다는 뜻으로 확대하지 않는다.

**근거:** [사규] 19쪽. 겸직·대외활동 세칙 미제공.

**암기법:** 회사 신분·직무로 돈 버는 외부활동 → 승인 기준 확인.

### 2번. 쌍둥이 회사축하금 20만원

**답·판정: X / 현재 사규 근거**

> 사원이 쌍둥이를 출산한 경우 회사는 출산축하금으로 20만원을 지급한다. ( ① ○   ② X ) (     )

회사 축하금은 자녀1명당20만원이므로 쌍둥이는 **20×2=40만원**이다. 이는 전액 지급 조건을 충족한 표 금액이다. 사우회 출산10만원과 합치거나 한 번의 출산 사건이라는 이유로 회사20만원 한 번만 계산하지 않는다.

**근거:** [사규] 12쪽.

**암기법:** 회사20 × 아이2 =40.

### 3번. DB 퇴직연금 중도인출

**답·판정: X / 퇴직연금 제도 구별**

> 확정급여형 퇴직연금의 적립액에 대하여 직원은 법정 사유에 해당하는 경우 중도인출 신청을 할 수 있다.
> ( ① ○   ② X ) (     )

**확정급여형(DB)** 적립액을 직원 개인이 법정사유에 따라 중도인출하는 방식은 아니다. 법정 사유에 따른 중도인출은 DC·개인형퇴직연금 등 해당 제도에서 따로 판단한다. DB 적립액 담보·퇴직금 중간정산 등 다른 절차와도 구분한다. 회사는 대리 이하 DB, 과장 이상 DC라는 현재 적용구분을 적고 있다.

**근거:** [사규] 22쪽. [외부] 근로자퇴직급여 보장법의 중도인출·제도 구분.

**암기법:** DB는 받을 급여의 기준 / DC는 납입 기여금의 기준. 인출 규칙도 다르다.

### 4번. 입원요건 없는 미숙아 출산 100일

**답·판정: X / 현재 사규 근거**

> 임신근로자가 임신 37주 미만에 출산하였으나 출생 후 24시간 이내 신생아 중환자실에 입원하지 아니한 경우 출산전후휴가는 100일을 부여한다. ( ① ○   ② X ) (     )

100일 미숙아 출산휴가에는 임신37주 미만 출생 또는 체중2.5kg 미만이라는 기준과 함께 **출생 후24시간 이내 신생아중환자실 입원** 요건이 있다. 이 보기에는 입원하지 않았다고 했으므로 일반 단태아90일이다. 다태아120일은 별도 구분이다.

**근거:** [사규] 9쪽.

**암기법:** 미숙아 조건 +24시간 내 중환자실. 앞 조건만으로100 X.

> ( ① ○   ② X ) (     )

재직 중에는1월1일~12월31일의 회계연도를 사용하고, 최종 퇴직 시에는 **입사일 기준으로 정산**한다. 두 기준을 같이 운영할 수 있다는 내용이다. 회사 기본연차22일·근속가산·첫1년 월개근 연차와 연결해 계산한다.

**암기법:** 재직 달력은1~12월 / 퇴직 계산은 입사일로 되돌린다.

### 6번. 육아휴직·배우자출산휴가 3회 분할

> 육아휴직 및 배우자 출산휴가는 각각 3회 분할하여 사용할 수 있다. ( ① ○   ② X )   (     )

현재 일반 육아휴직과 배우자출산휴가는 각각 **3회 분할** 가능하다. 세 번 나누면 최대 네 사용 구간이다. 2024년의 일반 육아휴직2회·배우자출산휴가1회 분할 기준과 다르다. 현재 PDF의 임신 중·단기 육아휴직 분할 예외도 별도로 읽는다.

**근거:** [사규] 10~11쪽. [외부: 개정 안내](https://moel.go.kr/policy/policydata/view.do?bbs_seq=20250100172)

**암기법:** 칼질3번 → 조각4개. 횟수와 구간은 다르다.

### 7번. Medical 주도면 판매촉진 면책인가

**답·판정: X / CP 근거**

> 제품설명회 진행 시 판매촉진, 사용유도 활동도 Medical이 주도하면 면책된다 ( ① ○   ② X )   (     )

Medical 부서가 진행했다는 이름표만으로 판매촉진·사용유도 행위가 면책되지 않는다. CP는 의약학적 가치와 적정한 목적·활동의 실질을 함께 보도록 설명한다. 판매를 유도하는 활동을 Medical 행사라고 부르는 것만으로 규제가 없어지는 것은 아니다.

**근거:** [CP] 28~29쪽.

**암기법:** 주최 부서 이름이 면책권은 아니다.

### 8번. 학술대회 예상비용 지원

**답·판정: X / CP 근거**

> 약사법상 허용되는 경제적 이익 등의 범위에 학술대회에 참가하는 발표자가 학술대회 주최자로부터
> 지원받는 교통비·식비·숙박비·등록비 용도의 예상 비용은 포함된다. ( ① ○   ② X )  (     )

발표자·좌장·토론자가 학술대회 주최자로부터 지원받는 교통·식비·숙박·등록비는 조건을 충족한 **실비용**이다. 원문의 예상비용이 함정이다. 지출할 것 같다는 금액을 일괄 주는 것과 실제로 든 비용을 적정하게 지원하는 것은 다르다.

**근거:** [CP] 6쪽.

**암기법:** 예상 = 앞으로 들 것 / 실비 = 실제로 든 것.

### 9번. 근로시간

**답·판정: ⑤ / 사규·외부 근거**

> 다음 중 우리회사의 근무시간제도와 관련하여 틀린 것은? (   )
> ① 일반 사무직의 경우 시차출퇴근제를 신청하여 출퇴근시간을 조정할 수 있으나, 1일 근로시간은 8시간을 준수하여야 한다.
> ② 임신근로자로서 임신 12주 이내인 경우 1일 2시간의 근로시간을 단축을 신청할 수 있다.
> ③ 유연근무제도를 적용하더라도 타 부서와의 협업 및 업무의 원활한 진행을 위해 집중근로시간을 설정하여 적용할 수 있다.
> ④ 우리회사의 재량근로시간제는 소정근로일에 모두 출근하여야 한다.
> ⑤ 관련 법령에서 정한 유해/위험 업무에 종사하는 경우 1일 근로시간은 7시간, 1주 근무시간은 35시간이다.

⑤의 ‘1일 7시간·1주 35시간’을 **1일 6시간·1주 34시간**으로 고쳐야 한다. 법령에서 특별히 정한 유해·위험 작업에 관한 기준이며 모든 생산업무에 자동 적용되는 것은 아니다.

**[사규 근거]** 7쪽. ①의 시차출퇴근은 출퇴근 시각을 조정하되 근로시간을 유지하는 제도다. ②의 임신 12주 이내 단축은 맞는 설명이며, 32주 이후도 대상이다. ③의 집중근로시간은 협업을 위해 함께 일하는 시간대를 정한다는 취지다. ④의 회사 재량근로제 출근 의무는 상세 운영규정이 없어 독립적으로 검증하지 못했다.

**암기법 [구분]:** 시차는 ‘시각 이동’, 단축은 ‘시간 감소’. 유해작업 숫자는 **6·34**.

**답·판정: 33일 / 출근율·월개근 충족 전제**

**근거:** [사규]8쪽.

**암기법:** 첫해11 +1년 뒤 회사22 =33.

## 5. 추가·정정·미확인 사항
