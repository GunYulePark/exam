## 3. 객관식·OX 해설

### 1번. 정년의 월말·연말 구별

**답·판정: X / 현재 사규 근거**

> 우리회사의 정년은 만 60세에 달한 해당월의 말일이다. ( ① ○   ② X ) (     )

만 60세에 달한 **해당 년도의 말일**이 기준이다. 해당 월의 말일이 아니다. 예를 들어 1970-01-01 출생자가 계속 재직한다면 만 60세가 되는 2030년의 12월 31일을 기준으로 본다. 출생일 자체·월말·연말을 구별한다.

**근거:** [사규] 18쪽. 과거 정년 규정 원문은 미제공이므로 당시도 같은 조항이었다는 전제의 복원답이다.

**암기법:** 60세 생일을 지나 그해 마지막 달력 장까지.

### 2번. 수습 중 부적격자의 본채용 거부

**답·판정: O / 현재 사규 근거**

> 수습기간 중 사원으로서 자질이 부족하다고 판단되는 경우 본채용을 거부할 수 있다. ( ① ○   ② X ) (  )

수습기간 중 자질·적성이 부적격한 경우 본채용을 거부하거나 입사 취소할 수 있다는 취지다. 실제 해고는 사유·절차의 정당성이 필요하므로 회사가 아무 이유 없이 해고해도 된다는 뜻은 아니다. 수습기간은 근속에 포함되고, 경력자의 수습은 단축·면제 가능하다.

**근거:** [사규] 17쪽.

**암기법:** 수습은 적격 여부를 보는 기간. 근속 달력은 계속 간다.

### 3번. 사우회 경조금 50%

**답·판정: O / 현재 사규 근거**

> 사우회비를 1년 미만 납입한 자는 경조사 발생시 경조금의 ½만 지급한다. ( ① ○   ② X ) (     )

사우회비 **12개월 미만 납입자는 50%, 12개월 이상은 100%**다. 회사 경조금의 근속 1년 기준과 다르다. 사우회 가입이 수습 후이므로 입사 1년과 회비 납입 12개월은 같은 시점이 아닐 수 있다.

**근거:** [사규] 12~13·21쪽.

**암기법:** 회사 봉투는 근속 시계, 사우회 봉투는 회비 시계.

### 4번. 7본부 1연구소인가

**답·판정: X 예상 / 당시 조직도 필요**

> 우리회사의 조직은 7본부 1연구소로 구성되어 있다. ( ① ○   ② X ) (     )

2024 주임 주관식 3번은 **6개 본부·1개 연구소**라고 직접 제시한다. 따라서 같은 기출 묶음의 7본부 설명은 X라는 출제 의도로 읽힌다. 현재 2026년 사규 6쪽은 **5본부·1연구소**이므로 당시 6본부의 이름을 현재 조직으로 대체하지 않는다. 시험 표기 연도와 조직도 기준일이 다를 수 있다.

**근거:** [기출 교차근거] 2024 주임 주관식 3번. [사규] 현재 조직은 6쪽. 당시 조직도 미제공.

**암기법:** 과거 6, 현재 PDF 5. 숫자 옆에 기준연도를 쓴다.

### 5번. 육아기 단축에 1년 근속이 필수인가

**답·판정: X / 외부·현재 규정 대조**

> 육아기 근로시간 단축은 회사에 1년 이상 근무한 사원만 신청할 수 있다. ( ① ○   ② X ) (     )

법정 허용 예외의 계속근로기간은 **6개월 미만**이며, 1년 이상 근무한 사람만 신청 가능하다는 설명은 틀리다. 근속요건과 고용보험 단축급여의 피보험단위기간 요건도 별개다. 2024년의 자녀 나이·최대 단축기간은 현재와 다르지만 이 문항의 1년 필수 주장은 맞지 않는다.

**근거:** [외부] 남녀고용평등법 시행령의 육아기 단축 허용 예외. [고용노동부 개정 제도 안내](https://moel.go.kr/policy/policydata/view.do?bbs_seq=20250100172)

**암기법:** 1년만 가능 X. 법정 허용 예외는 6개월 미만.

### 6번. 신원보증 갱신 누락

**답·판정: O / 현재 사규 근거**

> 신원보증을 기한 내 갱신하지 않으면 상벌규정에 의거 모든 서류가 완비될 때까지 출근을 중지시킬 수 있다.
> ( ① ○   ② X ) (     )

신원보증을 갱신하지 않으면 징계규정에 따라 모든 서류가 완비될 때까지 출근을 중지시키는 조항이 있다. 보험료 금액을 묻는 문제와 달리 여기서는 갱신 의무·서류 완비를 묻는다.

**근거:** [사규] 14쪽.

**암기법:** 보증 서류가 비면 출근 문이 닫힌다.

### 7번. 청탁금지법 위반과 회사의 주의·감독

**답·판정: O / 외부 법령 근거**

> CKD의 임직원이 업무상 청탁금지법을 위반하는 경우에 회사가 그 위반행위를 방지하기 위하여 해당 업무에
> 관하여 상당한 주의와 감독을 충실히 하는 경우에 회사는 면책될 가능성이 있다. ( ① ○   ② X ) (     )

직원 등의 업무 관련 위반에 대해 법인도 처벌받을 수 있는 양벌규정이 있지만, 해당 업무에 상당한 주의·감독을 게을리하지 않은 경우 법인의 예외가 인정될 수 있다. **직원 개인의 위반 자체가 없어지는 것은 아니다.** 약사법의 양벌규정과 취지가 비슷해도 이 문제는 청탁금지법 제24조를 근거로 읽는다.

**근거:** [외부] 청탁금지법 제24조. [국민권익위원회 청탁금지법 안내](https://www.acrc.go.kr/menu.es?mid=a10101060100)

**암기법:** 회사가 감독을 다했나 별도로 본다. 직원 면책과 회사 예외는 구분.

### 8번. 법정 목적·금액 범위의 금품 예외

**답·판정: O 조건부 / 예외 요건을 모두 충족할 때**

> 청탁금지법상 원활한 직무수행 또는 사교·의례 또는 부조의 목적으로 제공되는 음식물·경조사비·선물 등으로서
> 대통령령으로 정하는 가액 범위 안의 금품을 공무원에게 제공하는 것은 청탁금지법 위반에 해당하지 않는다.
> ( ① ○   ② X ) (     )

원활한 직무수행·사교·의례·부조라는 법정 목적과 대통령령의 가액 범위를 모두 충족하면 예외가 될 수 있다는 설명이다. 숫자 안에 들어오기만 하면 항상 허용되는 것은 아니다. 인허가·평가 등 직접 이해관계, 대가·청탁 목적이 있으면 예외 성립 여부를 다시 판단한다. 과거 음식물 가액과 현재 가액을 섞지 않는다.

**근거:** [CP] 26쪽. [외부: 권익위 금품수수 금지·예외](https://www.acrc.go.kr/menu.es?mid=a10101060300)

**암기법:** 목적 AND 금액 AND 관계. 금액 하나만으로 허용 도장 X.

### 9번. 회사 휴일이 아닌 날

**답·판정: ① 예상 / ⑤도 쟁점 / 단일 정답 확인 필요**

> 다음 중 우리회사 규정에 의한 휴일이 아닌 것은? (   )
> ① 토요일                  ② 정부에서 임시공휴일로 지정한 날               ③ 하기휴가 3일
> ④ 5월 1일                 ⑤ 6월 6일이 일요일인 경우 그 다음 근무일

현재 사규의 유급휴일 목록에는 **토요일**이 없다. ② 임시공휴일, ③ 하기휴가 3일, ④ 5월 1일은 목록과 연결된다. 따라서 출제 의도는 ①로 보인다.

그러나 ⑤의 **현충일이 일요일이면 다음 근무일이 휴일**이라는 설명도 법정 대체공휴일 기준상 자동 성립하지 않는다. 현재 사규 7쪽의 일반적인 공휴일·대체공휴일 문구만으로 회사가 현충일 다음 근무일까지 별도 휴일로 정했다는 것을 확인할 수 없다. 당시 회사가 더 넓은 대체휴일을 보장했는지 원문 확인이 필요하다.

**근거:** [사규] 7쪽. [외부: 관공서 공휴일 규정 제3조](https://www.law.go.kr/lsInfoP.do?lsId=002404)

**암기법:** 토요일 휴무와 유급휴일은 구분. 모든 공휴일에 대체휴일이 붙지는 않는다.

### 10번. 법정교육 횟수 연결

**답·판정: ④ 예상 / ③의 횟수 표현도 주의**

> 다음 중 법정 의무교육 및 실시 횟수가 올바르게 짝지어지지 않은 것을 고르시오. (   )
> ① 장애인 인식개선교육, 연간 1회                          ② 성희롱 예방교육, 연간 1회
> ③ 개인정보 보호교육, 연간 1회                            ④ 산업안전보건교육, 연간 1회
> ⑤ 퇴직연금교육, 연간 1 회

④ 산업안전보건교육을 연간 1회로만 정리한 연결이 문제다. 일반 사무직·판매업무 직접 종사자는 **매반기 6시간**, 그 밖의 근로자는 **매반기 12시간**, 관리감독자는 **연간 16시간** 등 대상별 시간 기준이다. 2023-09-27 이후 반기 기준을 읽는다.

① 장애인 인식개선, ② 성희롱 예방, ⑤ 퇴직연금 교육의 연 1회 기준과 구별한다. ③ 개인정보 교육은 개인정보취급자의 교육·안전조치 의무와 관련되지만 ‘전 직원 연 1회’라는 횟수·대상을 법이 일률 고정한 것으로 외우면 안 된다. 출제 의도 ④와 문항의 엄밀성을 나눠 본다.

**근거:** [외부: 고용노동부 교육 안내](https://1350.moel.go.kr/rtmview.do?id=1000274271), [개인정보 교육 안내](https://1350.moel.go.kr/rtmview.do?id=1000320024)

### 11번. 출장보고·근태 사전결재

### 18번. 연구직 대리의 전액 신원보증보험

**답·판정: ③ 34,040원 / 현재 표로 복원·2023 요율 확인 필요**

## 5. 추가·정정·미확인 사항
