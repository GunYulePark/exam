# 2025년 사규 4급대상 정답 및 해설

작성일: 2026-10-12 | 원본을 보존한 별도 학습용 복사본

객관식·OX 20문항(4점×20=80점), 주관식 5문항(20점), 총 100점. 회사 공식 정답과 부분점수 기준은 제공되지 않았다.

**판정 안내:** 사규·CP 근거가 확인되는 답, 출제 의도를 추정한 예상답, 단일 답을 확정할 수 없는 보류를 구분했다. 과거 규정 전문이 없으면 현재 규정과의 일치만으로 당시 답을 확정하지 않았다. 복수 보기에 문제가 있으면 함께 표시했다.

**자료 기준:** 제공 회사규정 PDF와 CP 2027 PDF를 대조했다. 쪽수는 표지 포함 PDF 파일 쪽수다. 외부자료는 근거란에 따로 표시했다. 개정 전 기출과 현재 기준을 나눠 설명하며, 정답지 자체는 공식 답안이 아니다.

원문: 2025년 사규_4급대상.txt. 기존 2026년 주임 해설지는 별도로 유지했다.

## 3. 객관식·OX 해설

### 1번. 회사 출산축하금 20만원

**답·판정: O 조건부 / 현재 사규·2024 시작일 근거**

> 사원이 2024년 자녀를 출산한 경우 신청에 의거 회사 경조금 20만원을 지급한다. ( ① ○   ② X ) (     )

2024-01-01 이후 출산일 기준, **자녀 1명당 회사 20만원**이다. 회사 경조금의 근속기간 1년 미만 50% 규정·신청기한 등도 같이 읽는다. 기출의 일반 사례는 20만원으로 보지만 모든 신입사원에게 조건 없이 전액 지급한다는 문장으로 확대하지 않는다. 사우회 출산축하금 10만원과 다른 봉투다.

**근거:** [사규] 12쪽.

**암기법:** 회사20 × 아이 수 / 사우회10. 근속·납입 조건은 따로.

### 2번. 팀원의 국내출장 승인자

**답·판정: X / 현재 사규 근거**

> 팀원이 회사 업무로 국내 출장시 사업부장 또는 담당임원의 승인을 받아야 한다. ( ① ○   ② X )
> (     )

팀원은 **팀장 승인**이다. 사업부장 또는 담당임원의 승인을 받는 것은 팀장이다. 본부장은 대표이사, 사업부장·담당임원은 본부장 승인이며 해외출장에는 별도 승인선이 있다. 국내와 해외를 섞지 않는다.

**근거:** [사규] 8쪽.

**암기법:** 팀원은 팀장 / 팀장은 사업부장·담당임원. 한 단계씩.

### 3번. 징계 의결·처분 주체

**답·판정: O 예상 / 상세 징계규정 미제공**

> 징계처분은 인사위원회의 의결에 의해 대표이사가 행한다. ( ① ○   ② X ) (     )

인사위원회가 의결하고 대표이사가 징계처분을 한다는 출제 의도다. 같은 내용이 2024 주임 주관식 5번에 빈칸으로 출제됐다. 현재 요약 PDF는 징계사유·종류를 싣지만 의결·통보 절차 전체는 없다. 따라서 반복 기출로 복원한 예상답으로 표시한다.

**근거:** [기출] 2024 주임 주관식 5·2025 주임 13번의 공통 문구. [사규] 18~19쪽.

**암기법:** 위원회가 의결 / 대표이사가 처분.

### 4번. 난임휴가 연 3일

**답·판정: O 과거 / X 현재 / 적용일 확인 필요**

> 회사는 사원이 난임치료를 받기 위해 휴가를 신청하는 경우 연간 3일의 휴가를 부여한다. ( ① ○   ② X )    (     )

2025-02-22까지 법정 기준은 **연 3일, 그중 1일 유급**이었다. 따라서 그 시점 기준의 문장이라면 O다. **2025-02-23부터 연 6일, 그중 2일 유급**으로 확대되어 현재 기준에서는 X다. 시험 표기는 2025년이나 전년도 내용을 묻는 항목들이 있으므로 당시 출제기준일·교재 판본이 없으면 O/X 하나만 확정하지 않는다. 현재 PDF는 2026-11-27부터 유급4·무급2로 변경된다고 추가 표기한다.

**근거:** [사규] 9~10쪽 현재·예정 내용. [외부: 고용노동부 제도 개편](https://moel.go.kr/policy/policydata/view.do?bbs_seq=20250100172)

**암기법:** 과거3·1 / 2025-02-23부터6·2. 총일수와 유급일수 구분.

### 5번. 복직원 만료 전 10일 이내

**답·판정: X / 현재 사규 근거**

> 휴직 중인 사원이 복직하고자 하는 경우 휴직기간 만료 전 10일 이내에 복직원을 제출하여야 한다.
> ( ① ○   ② X ) (     )

현재 PDF는 **휴직기간 만료 전 7일 이내**에 복직원을 제출한다고 적는다. 10일 이내가 아니다. 휴직원은 개시 7일 이전, 연기원은 3일 이전이므로 숫자와 ‘이내·이전’까지 구별한다.

**근거:** [사규] 11쪽. 과거 복직기한 원문은 미제공.

**암기법:** 휴7 이전 / 연3 이전 / 복7 이내.

### 6번. 성희롱은 피해자만 신고 가능한가

**답·판정: X / 외부 법령·문구 근거**

> 직장 내 성희롱 행위 발생시 반드시 피해자가 직접 신고하여야 한다. ( ① ○   ② X ) (     )

성희롱 발생 사실을 알게 된 사람은 신고할 수 있다. 반드시 피해자가 직접 신고해야 하는 것은 아니다. 신고 접수나 인지 후 사업주는 지체 없이 조사하고 피해자 보호·비밀 유지·불이익 금지 등 필요한 조치를 해야 한다.

**근거:** [외부] 남녀고용평등법 제14조. [법령 원문](https://www.law.go.kr/LSW/lsInfoP.do?lsId=000130)

**암기법:** 피해자만 신고 X / 알게 된 사람도 신고.

### 7번. 학술대회 예상비용 지원

**답·판정: X / CP 근거**

> 약사법상 허용되는 경제적 이익등의 범위에 학술대회에 참가하는 발표자가 학술대회 주최자로부터
> 지원받는 교통비·식비·숙박비·등록비 용도의 예상비용은 포함된다. ( ① ○   ② X ) (     )

발표자·좌장·토론자가 학술대회 주최자로부터 지원받는 교통·식비·숙박·등록비는 조건을 충족한 **실비용**이다. 원문의 예상비용이 함정이다. 지출할 것 같다는 금액을 일괄 주는 것과 실제로 든 비용을 적정하게 지원하는 것은 다르다.

**근거:** [CP] 6쪽.

**암기법:** 예상 = 앞으로 들 것 / 실비 = 실제로 든 것.

### 8번. 판매목표 사전협의도 불공정행위인가

**답·판정: X / CP 유형 대조**

> 불공정거래행위에 해당되는 것은 구속조건부거래, 차별적 취급, 판매목표 사전 협의, 거래강제이다.
> ( ① ○   ② X ) (     )

구속조건부거래·차별적 취급·거래강제는 불공정행위 유형에 있지만, **판매목표 사전협의**를 그 자체로 불공정행위 유형이라고 할 수 없다. 문제는 일방적인 판매목표 **강제**와 협의를 바꾼 것이다. 협의라는 이름만 붙였어도 실질이 강요이면 별도 판단한다.

**근거:** [CP] 11~12·16쪽 불공정행위 유형·판매목표 강제.

**암기법:** 함께 협의와 일방 강제는 다르다.

### 9번. 주 40시간에 휴게시간 포함인가

**답·판정: ⑤ / 현재 사규 근거**

> 다음 중 우리 회사의 근로시간제도 관련하여 틀린 것은? (   )
> ① 본사 사무직 근로자는 직상급자의 승인을 받은 경우 1일 소정근로시간을 유지하면서 업무의 시작 및 종료 시간을 조정할 수 있다.
> ② 근무시간의 전부 또는 일부를 사외에서 근무하여 실근무시간의 산정이 어려운 경우에는 소정근로시간을 근무한 것으로 한다.
> ③ 생산본부 소속 근로자의 업무 시작 시간은 8시, 종료 시간은 17시이다.
> ④ 연구·개발 등 업무의 특성상 업무수행 방법 및 근로시간 배분을 근로자의 재량에 위임할 필요가 있는 업무에 종사하는 사원에 대하여는 근로자대표와의 서면합의로 정한 시간을 근무한 것으로 한다.
> ⑤ 근무시간은 휴식시간을 포함하여 1주 40시간으로 한다.

⑤는 휴식시간을 포함한다고 해서 틀린다. 소정근로시간은 **휴식시간을 제외하고 1일 8시간·주40시간**이다. 08~17시 사이 9시간 중 점심 12~13시를 빼면 근로 8시간이다. ① 시차출퇴근은 일·주 소정시간을 유지하면서 시각을 조정한다. ② 산정 곤란한 사외근무는 간주, ④ 연구 등의 서면합의는 재량근로와 연결된다. ③ 08~17시는 현재 정규 시간표와 맞는다.

**근거:** [사규] 7쪽.

**암기법:** 9시간 머무름 - 점심1 = 근로8. 휴게 제외40.

### 10번. 외할머니 회갑 휴가

**답·판정: ③ 예상 / 외조부모 생일 범위 확인 필요**

> 다음 중 특별유급휴가의 휴가 사유별 휴가 일수가 틀린 것은? (   )
> ① 배우자의 여동생 사망 - 1일
> ② 삼촌 사망 - 2일
> ③ 외할머니 회갑 - 1일
> ④ 할아버지 사망 - 3일
> ⑤ 동생 결혼 - 1일

① 배우자 여동생 사망 1일, ② 백숙부 사망 2일, ④ 본인 조부 사망 3일, ⑤ 본인 형제 결혼 1일은 9쪽 표와 연결된다. ③ 외할머니 회갑은 생일휴가 대상 표가 부모·조부모·배우자 부모라고 되어 있고 외조부모를 별도 적지 않아 제외하는 출제 의도로 보인다.

다만 사망휴가에는 외조부모를 명시하면서 생일 항목의 ‘조부모’ 범위를 자세히 정의하지 않았다. 따라서 회사가 외조부모도 포함하는지 상세 규정을 확인해야 한다. 회갑·칠순·팔순을 다시 쓸 수 있는지와 대상 친족 범위는 별개다.

**근거:** [사규] 9쪽.

**암기법:** 본인 형제와 배우자 형제, 조부모와 외조부모를 정확히 읽는다.

### 11번. 수습 중 사우회비 0.8%

**답·판정: ④ / 현재 사규 근거**

> 다음 중 우리 회사의 수습과 관련한 설명으로 틀린 것은? (   )
> ① 경력사원으로 입사한 경우 수습기간을 단축할 수 있다.
> ② 수습기간은 직종별로 달리 적용할 수 있다.

**[CP 근거]** 파일 2·5쪽. 신고와 의약품 품목허가를 같은 행정절차로 생각하면 식약처장을 고르기 쉽다.

**암기법 [이해]:** 제품 허가기관을 떠올리지 말고 **CSO 사업장 신고는 관할 지자체**라고 연결한다.

## 4. 주관식 해설·계산풀이

### 주관식 1번. 2024년 경영목표 (5점)

**답·판정: 정확한 회사 목표 문구 미확인 / 관련 신년사만 확인**

2024년 시무식 보도에서는 지속 가능한 성장 기반 마련과 내실 경영에 집중하는 방향을 확인했다. 그러나 시험 답란에 그대로 써야 하는 **공식 경영목표 문장**을 확인한 것은 아니다. 보도 내용을 조합해서 임의 문장을 정답으로 만들지 않는다. 당시 회사 경영목표 공지·학습자료가 필요하다.

**근거:** [외부 기사: 2024년 종근당 시무식](https://www.newsis.com/view/NISX20240102_0002578431). [사규] 현재5쪽은2025 목표칸이 비어 있고6쪽은2026 목표다.

**암기법:** 연도별 목표를 나란히 적되2024 정확한 문구는 확인칸으로 둔다.

### 주관식 2번. 사시 (3점)

**답·판정: 우수의약품을 개발하여 인류건강을 지키며 복지사회 구현에 이바지한다. / 사규 근거**

답란에는 원문을 그대로 쓴다. ‘우수’를 ‘혁신’으로, ‘지키며’를 ‘기여하며’로 바꾸면 공식 문구 재현과 달라진다. 의미가 비슷한 문장을 회사가 인정하는지 채점표가 없으므로 정확한 원문 암기가 안전하다.

**근거:** [사규]5쪽.

**암기법:** 우수의약품 개발 → 인류건강 지키기 → 복지사회 구현에 이바지.

### 주관식 3번. 당시6본부·1연구소 명칭 (4점)

**답·판정: 미확인 / 당시 조직도 원문 필요**

기출은 당시6개 본부와 연구소의 정확한 명칭을 요구한다. 현재2026 사규6쪽은 **5본부1연구소**, 사업소에는 효종연구소를 표시한다. 현재부서명이나 사원수 분류의 영업·마케팅·개발·생산·경영관리 명칭을 조합해서 과거6본부 전체라고 만들 수 없다. 당시 조직도·본부명 공식 표가 필요하다.

**근거:** [기출]문제의6본부1연구소. [사규]6쪽 현재 조직.

**암기법:** 현재 조직을 과거 답안에 복사하지 않는다.

### 주관식 4번. 고졸 여성의 대리까지 승진연한 (3점)

**답·판정: 11년 / 사규 표 계산**

고졸 여성은5급 입사로 보고 **5급→4급6년 +4급→주임3년 +주임→대리2년=11년**이다. 부장까지의17년은4급 입사자의 다른 문제다. 누락 없는 승진연한 합산이며 실제 승진 발령의 연초 처리·입사 시점까지 정확한 날짜를 계산하는 질문은 아니다.

**근거:** [사규]17쪽.

**암기법:** 고졸여6, 주임까지3, 대리까지2 →6+3+2=11.

### 주관식 5번. 두 국제표준 인증규격 (5점)

**답·판정: ISO37001,ISO37301 / CP 근거**

첫 빈칸 반부패·부패방지 경영시스템은 **ISO37001**, 둘째 준법·컴플라이언스 경영시스템은 **ISO37301**이다. 법규·규정·윤리강령 전반을 운영하는 체계가37301이다. 기출과 CP에 제정 시점 설명이 붙지만 이 문항의 답란은 규격 번호를 요구한다. 번호와 명칭을 순서대로 쓴다.

**근거:** [CP]31쪽.

**암기법:** 37001은 부패 방지 /37301은 준법 전반.

## 5. 추가·정정·미확인 사항

이 파일은 새 복사본이다. 기출 원본·사규 원본·기존 핵심자료·기존 해설지는 수정하지 않았다. 정답표에 암기법과 출처를 연결하고 각 문항에 설명을 추가했다.

2023년 경영목표는 외부 보도에서 복원했다. 2024·2025년 목표의 미확인 문구와 과거 본부명은 해당 문항에 표시했다. 난임휴가 등 개정항목은 적용일을 구분했고, 질병결근 3일 증빙은 사규 8쪽에서 확인했다.
